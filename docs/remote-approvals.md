# 本人微信授权与表单

审批连接和普通聊天投递分别处理：先核对原绑定会话处于打开状态，再通过 `thread/resume`
订阅同一会话，仅传 `threadId/excludeTurns`，不覆盖权限、工作区或模型配置，不创建新会话。

收到正式 `item/commandExecution/requestApproval` 后，按 `availableDecisions` 原顺序展示。
不假定每个客户端都提供 `decline`；`cancel` 会结束本轮，需明确展示，不用它偷偷替代拒绝。
长期规则和会话放行保留原位置，标明需电脑操作；不能完整展示的内容会说明限制；本轮权限申请另有适配，见下表。

本人明确回复有效编号后，桥接提交对应 JSON-RPC 单次决定，并等待 `serverRequest/resolved`。
该回执也可能来自电脑端处理或请求取消，因此只能说明请求已关闭；执行结果单独核对。
断线后的未确认提交不自动重发，重连后的新请求生成新编号。

状态记录绑定账号、会话和连接，包含到期时间；重复、过期、跨会话和未通知的数字不触发审批。
多个审批或同时有普通选项时必须携带完整审批编号。
数据库以增量 schema 变更保留旧记录，不清空任务或凭据。

## 验证范围

- 自动测试覆盖本人/群聊过滤、跨会话隔离、重复回复、电脑端关闭竞争、重启与断线失效、
  敏感或不完整命令回退、严格单次决定、编号顺序和审批通知优先级。
- 本机实测完成：本人微信选择单次允许，桥接记录决定，服务端关闭请求，测试命令退出码为 0。
- 本机确认长期允许项只提示电脑端操作，不提交长期规则。
- 未做真实“取消并结束本轮”的手机验收；未保证长期无人交互推送。
- 未将真实账号、审批编号、消息原文、会话记录或本机验证路径放入公开源码。

协议依据：[OpenAI App Server Approvals](https://learn.chatgpt.com/docs/app-server#approvals)。

通知采用精简格式：具体命令、目录、原因、原顺序选项与一行回复说明。
不截断实际命令、不把摘要当作完整授权正文。

## 无法在微信处理时

通知会说明具体原因，不回显被拦截的敏感内容。当前命令正文上限为 60,000 字符，
目录 300 字符，原因 400 字符；超过上限、敏感内容、控制字符、缺少字段、
命令附带的未适配额外权限或其他未支持类型会说明具体限制，此类通知没有可回复的有效授权编号。
长命令按 2,200 字符分段，所有段落投递成功后才可选择；失败或漏段时保持待处理。

## 类型适配（2026-11-11）

| 正式请求 | 手机操作 | 回执 |
| --- | --- | --- |
| commandExecution/requestApproval | 原顺序单次允许/拒绝/取消 | decision |
| mcpServer/elicitation/request 的工具授权 | Allow、Cancel；会话/长期项保留位置但不启用 | action/content/_meta，不回传请求中的 persist |
| item/tool/requestUserInput | 单题选编号；多题/文字按问题 ID 填 JSON | answers，保留原始问题 ID 与选项 label |
| MCP 普通表单 | 支持的简单类型/枚举选项或 JSON 填写；拒绝/取消 | 校验 required、类型、枚举、范围后发送 content |
| fileChange/requestApproval | 收到同一轮同一 item 的完整差异后单次允许/拒绝/取消 | decision；缺少差异或包含 grantRoot 则明确告知限制 |
| permissions/requestApproval | 本轮允许原请求的权限集合或拒绝 | permissions + scope=turn |

未知审批不再静默丢弃。支持的长详情分片发送，未全部送达前不提交选择。
仅一个已通知请求且无普通选项时，可发 Allow/Cancel；不能将“Allow”替用户转换为长期放行。
表单输入不猜测、不填默认值；多题和文本使用 `填写 A编号 {"字段或问题ID":"答案"}`。
私密输入、身份验证及未知 schema 仍有明确限制；不通过更改 Codex 权限设置规避。

真实客户端验证：四选项 MCP 工具授权已收到，微信编号触发 accept，服务端关闭请求且只读工具成功返回。
普通异步提问的一次现场测试仅产生历史通知，未收到正式请求，不能宣称该客户端的所有原生表单已接通。
日常方案选择继续使用显式卡片选项；收到正式表单时才走对应 answers 协议。
新增自动测试覆盖映射、完整内容、长命令末段未发送时禁止提交、分片、字段验证、过期、重复、身份隔离和原生竞争。
文件修改及权限申请目前有协议/自动测试证据，尚未完成手机现场操作。

协议依据：本机 Codex CLI 0.167.0 导出的 TypeScript schema，及
[官方 App Server 协议](https://learn.chatgpt.com/docs/app-server#approvals)、
[官方 MCP 授权构造代码](https://github.com/openai/codex/blob/main/codex-rs/core/src/mcp_tool_call.rs)。

手机超长请求实测：3,798 字符正文拆为 2 段，两段接口均接受且无需重试；本人回复编号后记录单次 accept，服务端关闭请求，测试命令成功退出。此证据不代表所有长度、长期无人交互或所有原生表单均已验证。
